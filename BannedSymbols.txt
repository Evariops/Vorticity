# APIs this repository refuses, enforced at COMPILE TIME by
# Microsoft.CodeAnalysis.BannedApiAnalyzers (RS0030). TreatWarningsAsErrors makes each one a
# build failure rather than a warning somebody scrolls past.
# Format: one `T:`, `M:` or `P:` docid per line, then `;`, then the message the compiler prints.
# The message has to say what to do INSTEAD, because it is the only thing the person who hit it
# will read. Blank lines are NOT allowed -- the analyzer reads them as an empty symbol (RS0031).
# A genuinely unavoidable use is suppressed at the site with `#pragma warning disable RS0030` and
# a comment saying why. That is the point: the exception becomes visible in review instead of
# being indistinguishable from the ninety uses that were never thought about.
# ---------------------------------------------------------------- scratch ownership
T:System.ThreadStaticAttribute; a thread-static is correct only while no await separates taking the state from finishing with it, and both entry points into this library (ScanBuilder, VortexFileWriter) are async -- so the property is never local to the code that relies on it. Put scratch on the context that owns the work (ScanContext on the read path), rent it for the decode that uses it (Scratch<T>), or transfer ownership of one cached instance explicitly (FsstSymbols.TrainingTables.Take/Give).
# ---------------------------------------------------------------- sync over async
# Blocking on a task is a deadlock on any caller with a synchronization context and a thread-pool
# starvation on every other. The whole read and write surface of this library is async; there is
# no correct place to bridge back. Await it, or make the caller async too.
M:System.Threading.Tasks.Task.Wait; await the task instead of blocking on it.
M:System.Threading.Tasks.Task.WaitAll; await the tasks instead of blocking on them (Task.WhenAll).
M:System.Threading.Tasks.Task.WaitAny; await the tasks instead of blocking on them (Task.WhenAny).
P:System.Threading.Tasks.Task`1.Result; await the task instead of blocking on it.
P:System.Threading.Tasks.ValueTask`1.Result; await the value task; reading Result before it completes is undefined, and blocking on it is worse.
M:System.Runtime.CompilerServices.TaskAwaiter.GetResult; await the task. Legitimate only to observe an ALREADY-completed task, which needs a suppression saying so.
M:System.Runtime.CompilerServices.TaskAwaiter`1.GetResult; await the task. Legitimate only to observe an ALREADY-completed task, which needs a suppression saying so.
M:System.Runtime.CompilerServices.ValueTaskAwaiter.GetResult; await the value task. Legitimate only to observe one whose IsCompletedSuccessfully has just been checked, which needs a suppression saying so.
M:System.Runtime.CompilerServices.ValueTaskAwaiter`1.GetResult; await the value task. Legitimate only to observe one whose IsCompletedSuccessfully has just been checked, which needs a suppression saying so.
M:System.Threading.Tasks.Task.RunSynchronously; there is no synchronous path through this library.
M:System.Threading.Thread.Sleep(System.Int32); blocking a pool thread. Use Task.Delay in async code; in a test, wait on the thing that actually changes.
# ---------------------------------------------------------------- zstd
# vortex.zstd, vortex.zstd_buffers and Parquet's ZSTD go through ManagedCompressions.Zstd, a managed
# zstd: nothing native per scan or per writer, and faster than the runtime's libzstd at decompression.
T:System.IO.Compression.ZstandardDecoder; decompress with ManagedCompressions.Zstd.ZstdDecompressor, the scan's through ScanContext.Zstd (pooled by ZstdDecoders).
T:System.IO.Compression.ZstandardEncoder; compress with ManagedCompressions.Zstd.ZstdCompressor, the writer's through Workspace.Zstd (pooled by ZstdEncoders).
T:System.IO.Compression.ZstandardDictionary; pass the dictionary's bytes to the ZstdDecompressor or ZstdCompressor constructor of ManagedCompressions.Zstd.
T:System.IO.Compression.ZstandardCompressionOptions; ManagedCompressions.Zstd.ZstdCompressor takes its level and dictionary in its constructor.
T:System.IO.Compression.ZstandardStream; ManagedCompressions.Zstd compresses and decompresses whole frames in memory: ZstdCompressor, ZstdDecompressor.
# ---------------------------------------------------------------- native memory
# The library allocates no native memory: the collector is the only allocator of every byte it holds,
# so that a limit on the heap is a limit on the library, and a process past it gets an exception rather
# than a kill. A block is a managed array the runtime pins (BlockOwner), a secret a pinned array
# wiped on dispose (SecretBytes). Mapped files and system calls are the system's, not allocations.
T:System.Runtime.InteropServices.NativeMemory; allocate a pinned managed array (GC.AllocateUninitializedArray with pinned: true), as BlockOwner does for an aligned block.
M:System.Runtime.InteropServices.Marshal.AllocHGlobal(System.Int32); allocate a managed array, pinned when its address must not move.
M:System.Runtime.InteropServices.Marshal.AllocHGlobal(System.IntPtr); allocate a managed array, pinned when its address must not move.
M:System.Runtime.InteropServices.Marshal.AllocCoTaskMem(System.Int32); allocate a managed array, pinned when its address must not move.
M:System.GC.AddMemoryPressure(System.Int64); the library's memory is managed, and the collector already counts it.
M:System.GC.RemoveMemoryPressure(System.Int64); the library's memory is managed, and the collector already counts it.
# ---------------------------------------------------------------- pooled arrays
# Every array the library rents comes from one pool, Blocks, which keeps one stack per size class, counts what it holds in
# the memory report and gives it back to the registry of kept memory (HeldMemory) when the work needs the room or no rent
# took it of late. The runtime's shared pool keeps arrays per type and per core, outside every count, and a private pool is
# one more such.
P:System.Buffers.ArrayPool`1.Shared; rent a Block<T> from Blocks (Blocks.Rent, Blocks.Return), under the query's memory where one counts (Blocks.Rent(memory, ...)), or bytes from VortexBytePool.Instance; an array that holds references is owned by what lasts, or allocated.
M:System.Buffers.ArrayPool`1.Create; rent from Blocks, which every array of the library comes from, rather than a pool of its own.
# ---------------------------------------------------------------- accounts
# A block of the pool is rented under the account of the work it serves (MemoryAccount): a query's, a scan's, a writer's,
# the process's for what the library gives back itself. The arenas' constructors without an account are the tests' and
# the tools': their blocks are the caller's, counted nowhere.
M:Vorticity.Arrays.CanonicalArena.#ctor(System.Int32); name the account of the arena's work: new CanonicalArena(capacity, account).
M:Vorticity.Arrays.RetainingArena.#ctor(System.Int32); name the account of the scan whose chunks it retains: new RetainingArena(account, capacity).
